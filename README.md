## 📖 نبذة

منصة تعليمية **Full-Stack** جاهزة للإنتاج، تدعم **العربية (RTL) والإنجليزية**، والوضع **الليلي والنهاري**، وقابلة للتثبيت على الموبايل كتطبيق **PWA** بدون متجر تطبيقات.

## ✨ أهم المميزات

### 🔐 المصادقة والأمان
- تشفير كلمات المرور بخوارزمية **scrypt** مع Salt عشوائي لكل مستخدم
- **جلسات حقيقية** بتوكن عشوائي محفوظ في قاعدة البيانات مع صلاحية 7 أيام
- **قفل الحساب** تلقائياً بعد 5 محاولات دخول خاطئة لمدة 10 دقائق
- صلاحيات دقيقة بالأدوار على مستوى الـ API (RBAC)
- عدم تسريب كلمات المرور في أي استجابة أو نسخة احتياطية

### 👥 أربعة أدوار
| الدور | الصلاحيات |
|------|-----------|
| 👑 **المشرف العام** | تحليلات، إدارة المستخدمين، أكواد التفعيل، المدفوعات، النسخ الاحتياطي |
| 👨‍🏫 **المعلم** | نشر الكورسات، رفع PDF، بنك الأسئلة، الواجبات، الحضور، التصحيح |
| 🎓 **الطالب** | الدروس، الامتحانات، الواجبات، الشهادات، التقارير، الجيميفيكيشن |
| 👨‍👦 **ولي الأمر** | متابعة الحضور والدرجات والتقارير + تواصل واتساب مباشر |

### 🧠 بنك الأسئلة الذكي ومولد الامتحانات
- بنك مفهرس يدعم **100,000+ سؤال** (قواعد + مفردات) مع فهارس PostgreSQL
- تصنيف كامل: المرحلة، الصف، الوحدة، الدرس، الصعوبة، المهارة، نوع الكلمة، الموضوع، **مستوى بلوم**
- تغطية كل مواضيع القواعد: الأزمنة، المبني للمجهول، الكلام المنقول، الشرطية، الأفعال الناقصة، جمل الوصل، حروف الجر، الاشتقاق...
- **مولد امتحانات ذكي**: بدون تكرار أسئلة، خلط الاختيارات، موازنة القواعد/المفردات، حفظ كل امتحان
- **توليد أسئلة بالذكاء الاصطناعي** مع **كشف التكرار** (fuzzy matching) قبل الحفظ
- **استيراد جماعي** من CSV / Excel / Word مع تصنيف تلقائي
- إحصائيات لكل سؤال: عدد الاستخدام، معدل الإجابة الصحيحة، معامل الصعوبة والتمييز

### 📚 المحتوى التعليمي
- كورسات للصفوف الستة (أولى/ثانية/ثالثة إعدادي + أولى/ثانية/ثالثة ثانوي)
- **مشغل فيديو محمي**: علامة مائية متحركة باسم ورقم الطالب، منع التحميل، سرعات تشغيل، ملاحظات بالتوقيت
- **مكتبة PDF محمية**: رفع من المعلم، عارض مدمج، علامة مائية، إشارات مرجعية، منع النسخ
- **اختبار تحديد مستوى تكيفي** بستة مستويات مع توصيات آلية

### 📝 الواجبات والحضور
- نشر الواجبات ← تسليم الطالب (نص أو ملف) ← تصحيح بدرجة وملاحظات + إشعار فوري
- رصد الحضور الجماعي (حاضر/متأخر/غائب/معذور) + تسجيل ذاتي + تقويم 30 يوم

### 🔔 الإشعارات
- **Web Push حقيقي** (VAPID) يصل للجهاز حتى والتطبيق مقفول
- مركز إشعارات كامل + بث جماعي للمعلم + عداد لحظي

### 📊 التقارير والتحليلات
- مؤشر أداء شامل، منحنى تطور الدرجات، **خريطة إتقان المواضيع**
- تحديد **نقاط القوة والضعف** تلقائياً + توصيات ذكية
- تقرير فصل كامل للمعلم مع ترتيب الطلاب والطلاب المتعثرين
- طباعة التقارير ومشاركتها عبر واتساب

### 💳 المدفوعات المصرية
فودافون كاش · إنستاباي · فوري · Stripe · **أكواد التفعيل**

### 🎮 الجيميفيكيشن والإضافات
لوحة متصدرين · أوسمة · تتابع يومي · نظام إحالة · مفضلة · تقويم حصص · مؤقت بومودورو · مخطط مذاكرة · مساعد AI خماسي · شهادات بـ QR · مدونة · شات مجتمع · بحث شامل

### 📱 تطبيق موبايل (PWA)
قابل للتثبيت على أندرويد وآيفون · يعمل بدون إنترنت · اختصارات سريعة · صفحة تحميل بكود QR

## 🚀 التشغيل محلياً

```bash
# 1) تثبيت الحزم
npm install

# 2) إعداد متغيرات البيئة
cp .env.example .env
#    ثم عدّل DATABASE_URL بقاعدة بياناتك

# 3) إنشاء الجداول (تُنشأ تلقائياً عند أول طلب أيضاً)
npx drizzle-kit push

# 4) التشغيل
npm run dev      # وضع التطوير  → http://localhost:3000
npm run build && npm start   # وضع الإنتاج
```

## 🗂️ هيكل المشروع

```
src/
├── app/
│   ├── api/            # كل مسارات الـ API (auth, courses, question-bank, pdfs,
│   │                   #  homework, attendance, notifications, analytics, ...)
│   ├── layout.tsx      # SEO + Schema.org + إعدادات PWA
│   ├── manifest.ts     # ملف تعريف تطبيق الموبايل
│   └── page.tsx        # التطبيق الرئيسي (توجيه كل الشاشات)
├── components/         # كل واجهات المنصة (30+ مكوّن)
├── config/             # أرقام التواصل وإعدادات المنصة
├── context/            # حالة التطبيق (مصادقة، لغة، ثيم، إشعارات)
├── db/                 # مخطط Drizzle + الهجرة + البيانات التجريبية
└── lib/                # الأمان، Push، أدوات العميل
```
